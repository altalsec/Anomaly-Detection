This repository presents a lightweight web-based analytics tool designed to explore and evaluate datasets generated by the CYEYE cyber intelligence platform.

The application provides an interactive, single-page interface that allows users to upload CSV datasets and instantly visualize their structure, quality, and statistical properties. It is specifically tailored for datasets derived from large-scale intelligence collection pipelines, including Telegram monitoring, OSINT sources, and anomaly detection outputs.

Notes
This is a local analysis tool intended for testing and research purposes
Current version supports CSV files only
Large datasets may require increasing upload limits or preprocessing
Future versions will support streaming, real-time dashboards, and direct database integration

Author

Developed as part of ongoing research in cyber intelligence, anomaly detection, and automated investigation systems.
